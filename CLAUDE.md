# Task System

- Active tasks live in `tasks/active/`, completed in `tasks/completed/`
- Backlog lives in `backlog/BACKLOG.md`
- Task naming: `YYYY-MM-DD-[category]-description.md`
- Priorities: P0 (Today, max 3), P1 (This week, max 7), P2 (Scheduled)
- Knowledge, goals, wins, and decisions are tracked in `knowledge/private/`
