This `backlog/` folder and `BACKLOG.md` are for you or your LLM to quickly jot down incoming tasks or requests, and store any relevant reference material.

For example: suppose you're asked to investigate a visual bug on an input field for a flow you own. You might add "ticket text box bug" to BACKLOG.md, and place a screenshot, "text box bug.jpg", into `backlog`.

When you're ready to organize, say something like "process my backlog" and your LLM will categorize and prioritize everything. This triggers the `process` skill (`.claude/skills/process/SKILL.md`).
