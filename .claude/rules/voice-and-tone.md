# Voice & Tone

Apply these rules to all written output: proposals, frameworks, presentations, emails, Slack messages, and strategic docs.

## Core Principles

- **Be Direct**: Lead with the point, not the context. One idea per sentence. Short paragraphs (2-8 sentences max).
- **Be Specific**: Use real numbers, not "significant" or "many." Show calculations. Attribute data sources inline.
- **Be Concise**: Cut unnecessary words. No corporate-speak. No warm-up paragraphs.
- **Be Simple**: Plain language over technical terms. Common words over synonyms for flair. Use analogies when helpful.

## Sentence Style

**Good:**
- "AI is transforming how users discover information, presenting both a challenge (60% of searches now end without clicks) and an opportunity."
- "If we [build this], then [metric] will improve because [behavior change]."

**Bad:**
- "There are several key challenges and opportunities that we should be thinking about."
- "We believe this could potentially have a positive impact on metrics going forward."

## Opening Documents

- **Proposals (TL;DR):** What you're proposing + the goal + how you'll measure success. 2-3 sentences max.
- **Frameworks (Executive Summary):** Problem statement (first sentence) + recommendation with resource allocation + key risks + critical questions.

## Presenting Data

Lead with the insight, then cite the source:
- Good: "Users search 10% more frequently when AI results are shown ([source])"
- Bad: "According to the data, there has been an increase in search frequency"

## Hypothesis Format

Always use: "If we [build this] then [this metric] will move because [this change in behavior]"

## Banned Phrases

| Banned | Use Instead |
|--------|-------------|
| boost, enhance, robust | improve, strengthen, reliable |
| Key insight | [just state the insight] |
| Moving forward / Going forward | [delete] |
| At the end of the day | [delete] |
| It's worth noting that | [delete] |
| Em dashes (---) | commas, periods, or parentheses |
| leverage (as verb) | use |
| utilize | use |
| synergy | [delete or be specific] |

## Voice Checklist

Before sending any document:
- Starts with the point, not context
- Short paragraphs (2-8 sentences max)
- Specific numbers with attribution
- No banned phrases
- No em dashes
- Recommendations stated clearly ("I recommend...")
- Risks acknowledged with mitigations
